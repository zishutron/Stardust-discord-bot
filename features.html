Features

Everything you need to run a great server.

Stardust ships with 40+ slash commands across 8 core modules — all connected to a single dashboard.

Moderation AutoMod Welcome Tickets Economy Leveling Giveaways Games Utilities
Moderation

Enforce rules without friction.

Every action is guarded by Discord's native permission system and role hierarchy.

Kick & ban

Remove members with an optional reason. Bans are permanent and logged server-side.

Timeout

Mute members for any duration. Ideal for temporary cool-downs.

Warnings

Issue formal warnings with reasons. Members receive a private DM notification.

Role management

Add or remove roles from members. Bot role hierarchy is validated before every action.

AutoMod

Automatic protection, per-server.

Configure the block list directly from the dashboard — no commands needed.

  • Custom blocked-word list per server
  • Instant message deletion on match
  • Ephemeral warnings auto-removed after 4 seconds
  • Toggle the entire system on/off from the dashboard
Welcome & Leave

Greet members the moment they arrive.

Rich embed cards with custom imagery and member counts.

  • Welcome channel with formatted card embed
  • Separate leave channel with custom message templates
  • {user} and {server} placeholders supported
  • One-click test trigger via /welcome-test
Tickets

A complete support helpdesk.

Private channels, staff claiming, transcripts, and full log archiving.

  • Deployable support panel via /ticket_setup
  • Private ticket channels with proper permission overwrites
  • Staff "claim ticket" button with moderator attribution
  • Automatic transcripts on close — sent to #ticket-logs
  • Customizable welcome title and message via /ticket_config
Economy

Currency, rewards, and a global shop.

Member balances, chat rewards, a 16-dish menu, premium shop, and inventory.

Daily rewards

200 coins every 24 hours via /daily.

Chat wages

Random 5,000–75,000 coin drops when members chat (10% chance).

Global menu

16 premium dishes from around the world, purchasable with /serve.

Shop & inventory

Pets, badges, and collectibles with /buy and /inventory.

Leveling

Progression that feels rewarding.

Free Fire–style tier system with custom rank cards.

  • XP gained per chat message (60s cooldown per user)
  • Custom rank card with avatar, tier, XP progress bar
  • Level-up announcements with a generated image
  • 12 tiers from 🥉 Bronze I through 👑 Grandmaster
Giveaways

Host giveaways in seconds.

Reaction-based entry with automatic winner selection.

  • Duration parsing (30m, 5h, 1d)
  • Multiple winners per giveaway
  • Auto-conclusion with winner pings
  • Startable from the dashboard or via /gstart
Games & Anime

Fun that keeps members coming back.

Interactive games with economy rewards and roleplay actions.

Rock Paper Scissors

Play vs a member or the bot. Winners get 100 coins.

Tic Tac Toe

Full 3×3 grid game with a winner bonus.

Slap fight

HP-based interaction game with 250 coin rewards.

Anime roleplay

/hug, /kiss, /slap with animated GIFs.

Waifu & husbandu

Claim characters from $w and $m commands.

Confessions

Anonymous confession box with a reply system.

Utilities

Quality-of-life tools for everyone.

  • /embed_builder — interactive custom embed modal
  • /matrixpoll — native Discord reaction polls
  • /remindme — personal one-off reminders
  • /afk — AFK status with automatic mention responses
  • /rollmatrix, /stardustquote, /ping — quick utilities
