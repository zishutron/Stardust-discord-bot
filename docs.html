Introduction

Stardust is a multi-purpose Discord bot that brings moderation, automation, tickets, economy, leveling, and community tools together in a single, cohesive system.

Everything Stardust does is managed from one place: your server's Discord commands and the Stardust web dashboard. There is no separate CLI, no plugin install, no local software to run.

You need the Manage Server or Administrator permission to configure Stardust on a server.

Adding Stardust

Adding Stardust to your Discord server takes under 30 seconds:

  • Click the Add to Discord button in the header.
  • Choose a server where you have Manage Server permission.
  • Review the requested permissions and authorize.
  • Stardust will appear in your member list. You can verify it with /ping.

The bot requests administrator permissions to cover all features. If you prefer least-privilege, disable specific scopes you don't need after the install.

Using the dashboard

The Stardust dashboard gives you a clean UI for every configuration that would otherwise require dozens of commands. To access it:

  • Click Login in the site header.
  • Authorize with your Discord account.
  • You'll be redirected to Your Servers.
  • Click Manage on any server where you have admin access.

Every change you make is saved immediately to the Stardust backend and applied to the bot in real time.

Moderation

Stardust's moderation commands are native Discord slash commands. They respect Discord's permission system exactly as you'd expect.

Commands

/kick [member] [reason]
/ban [member] [reason]
/mute [member] [minutes] [reason]
/warn [member] [reason]
/addrole [member] [role]
/removerole [member] [role]

The bot's role must be higher than the target's highest role for kick, ban, and timeout to work.

AutoMod

AutoMod watches every message in your server and deletes any that contain blocked words.

  • Configure the block list from the dashboard — AutoMod tab.
  • Toggle the entire system on/off with a single switch.
  • Warnings are ephemeral (removed after 4 seconds).

Welcome & Leave

Announce new arrivals with a rich embed card and notify members when someone leaves.

/welcome-set [#channel]      # Set welcome channel
/welcome-test                # Test the welcome card
/welcome-reset               # Disable welcome

You can also configure the level-up channel and message from the dashboard's Welcome tab.

Tickets

Deploy a professional support panel in seconds. Members click a button, and Stardust opens a private channel for them.

/ticket_setup [#channel]                    # Deploy the panel
/ticket_config [panel_description] [welcome_title] [welcome_message] [staff_role]
  • Staff can claim tickets with the Claim button.
  • Closing a ticket generates a transcript saved to #ticket-logs.
  • Only the ticket owner and configured staff role can access each channel.

Economy

Stardust comes with a fully functional economy. Members earn coins by being active, and spend them on premium items.

/daily         # Claim 200 coins (24h cooldown)
/wallet        # View balance
/menu          # View food menu
/shop          # Browse shop items
/buy [item]    # Purchase an item
/inventory     # View your items
/serve [item] [member]   # Serve a dish

Admins can also configure a reward channel from the dashboard so random coin drops appear there.

Leveling

Members gain XP for every message they send (60-second cooldown per user). When they level up, Stardust generates a custom rank-up card.

/rank                     # View your rank card
/level-set-channel [#ch]  # Set level-up channel
/level-set-msg [message]  # Customize level-up message

Tiers progress from 🥉 Bronze I at level 1 up to 👑 Grandmaster at level 60+.

Giveaways

Reaction-based giveaways with automatic winner selection.

/gstart [duration] [winners] [prize]

Duration supports 30m, 5h, 1d formats.

Embed Builder

Compose custom embeds without leaving Discord, or use the dashboard's interactive embed builder with a live Discord-style preview.

/embed_builder [#channel]   # Opens an interactive modal

Permissions

Stardust requests the following permissions during install. You can remove any you don't need after installation.

  • Manage Server — read server metadata, list channels
  • Manage Roles — for role management commands
  • Manage Channels — for ticket channel creation
  • Kick Members — for /kick, /warn
  • Ban Members — for /ban
  • Moderate Members — for /mute (timeout)
  • Manage Messages — for AutoMod deletion
  • Send Messages + Embed Links — required for all output
  • Attach Files — for rank cards and level-up cards

Troubleshooting

Bot doesn't respond to commands

  • Verify Stardust is online with /ping.
  • Check that the bot has the required permission for that command.
  • Confirm the bot's role is higher than the target's highest role (for moderation actions).

Dashboard says "Backend unavailable"

  • The backend is hosted on Render's free tier, which sleeps after inactivity.
  • Wait ~30 seconds and try again — the server is waking up.
  • If it persists, contact support.

Login redirects back without logging in

  • Ensure cookies are enabled for both zishutron.github.io and stardust-bot.onrender.com.
  • Try logging out and logging in again.
